# Audio8 TTS Realistic 0.6B

The original `Edge0/Audio8-TTS-Realistic-0.6b` URL resolves to `Edge0/Audio8-TTS-Realistic-Air`. The model registry pins stephvax's independent INT4 ONNX conversion, revision `04313606782af6b9a1aa93724555bc7b64ba9197`. The conversion records the Realistic source revision `1e857568bfd4f02931aca3988ee773a44d2d26d3` and the original acoustic model's SHA-256. The tokenizer and codec are byte-identical between Preview and Realistic according to the converter. The two autoregressive transformers use the Realistic weights. [Edge0 checkpoint](https://huggingface.co/Edge0/Audio8-TTS-Realistic-Air/tree/1e857568bfd4f02931aca3988ee773a44d2d26d3) · [Conversion provenance](https://huggingface.co/stephvax/audio8-tts-realistic-0.6b-onnx-int4/blob/04313606782af6b9a1aa93724555bc7b64ba9197/provenance.json)

The selected configuration accepts English text and generates a voice without reference audio. Edge0 lists 23 languages and open-ended zero-shot voice support. The staged model has zero named voice presets. The three ONNX graphs and their external data contain 587,714,450 bytes of model assets. The tokenizer and browser runtime add to this download.

The browser adapter loads ONNX Runtime Web 1.31.1 with explicit CPU/WASM or WebGPU/WASM providers and six WASM threads in both configurations. For each source span the adapter encodes seven prompt segments independently with the checkpoint's tokenizer, places their concatenated token IDs into the semantic row and initializes the ten codec rows to zero. The slow transformer predicts a semantic token for each frame and the fast transformer completes its ten codebooks. The sampling settings are temperature 0.7, top-p 0.9 and top-k 50, with upstream repetition resampling and a JavaScript categorical draw seeded at 42 per span. Each span must reach EOS within 1,024 frames and the 2,048-position context window. A complete decoder invocation returns mono 44,100 Hz PCM after EOS. A separate untimed synthesis validates WebGPU dispatch. [Processor](https://huggingface.co/Edge0/Audio8-TTS-Realistic-Air/blob/1e857568bfd4f02931aca3988ee773a44d2d26d3/processing_arktts.py) · [Edge0 reference loop](https://github.com/Edge0-AI/Audio8_TTS/blob/1d64afcc2da56222b41ddcf53de7b8bc54be1fb6/onnx_runtime/arktts_runtime/runtime.py)

After staging assets, `node tools/check-audio8-frontend.mjs` compares all 93 canonical prompts against token IDs from Hugging Face's native tokenizer. For reproduction, `python tools/audio8-prompt-oracle.py` regenerates the text-only oracle with `tokenizers==0.22.2`.

The checkpoint and ONNX export use Apache-2.0. The tokenizer runtime uses Apache-2.0 and ONNX Runtime Web uses MIT. The upstream attribution and implementation changes are retained with the adapter. [Port notices](../web/audio8/NOTICE.md)
