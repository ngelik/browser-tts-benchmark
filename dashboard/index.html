Read the full protocol ↗
01 / GENERATION

Warm, full-article runs

20,000 English characters. The median of five scored articles after an excluded warm-up. CPU and GPU use their own execution paths; WebGPU may still include CPU operations. Historical runs have distinct timing protocols.

02 / MEMORY

Chrome, workers included

Mean sampled process RSS from a separate full-article diagnostic with one benchmark tab. Includes the browser baseline and may count shared pages more than once. It is neither model-only RAM nor GPU VRAM. Peaks and source receipts are in model details.

03 / MODEL SIZE

Weights, including vocoder

Verified core model files, in decimal MB. Runtime, voice files, text processing and transfer overhead are excluded. The downloaded bundle can be larger. Model and runtime licenses are listed separately in details.

04 / COMPARABILITY

Context stays with the score

This overview combines published cohorts. Source code, Chrome versions and protocols vary. Filter to a source cohort for closer comparisons. Only matched native CPU/GPU pairs share the required test configuration. Audio examples are not a quality ranking.
